# Cursor Skin Manager · 鼠标指针管理工具

一个 Windows 鼠标指针管理工具，使用 C# / WinForms 和 Windows 原生光标 API。

**不附带任何第三方指针皮肤、角色图片或素材包。首次使用请导入你有权使用的 ANI / CUR 文件。**

## 功能

- 导入 ANI 动画光标和 CUR 静态光标文件夹，识别并手动检查 17 种指针用途；缺失用途使用本机 Windows 默认。
- 独立临时预览：选择皮肤、用途和大小后，将鼠标移入白色区域即可试用；移出恢复，点击应用前不修改系统方案。
- 0.5～8 倍大小调节，每款导入皮肤分别记忆大小。
- 可选的本机色差补偿（0.50～2.50），默认 1.00 不补偿；仅生成缓存副本，保留导入原件、热点、透明度和动画顺序。
- 撤销上次更改，恢复 Windows 默认和 1×，恢复首次应用本工具前的指针及大小。
- 导入时复制素材，后续使用不依赖原下载文件夹；不执行素材包中的安装程序或 INF。

## 运行

需要 Windows 10 1607 及以上版本或 Windows 11，以及 .NET Framework 4.8。无须 Python、Node.js 或管理员权限。

下载仓库 `downloads/` 内的 `CursorSkinManager.exe`，或从 Actions 中下载最新构建产物。双击启动后点击“导入新皮肤”，选择一个含 ANI / CUR 文件的文件夹，检查用途对应关系并导入。压缩包请先自行解压。

选择皮肤、用途和大小，在白色区域试用，再点击“使用这款皮肤和大小”。输入数值后约 250ms 更新预览，无需先按回车。大小快捷按钮仅更新预览。

色差补偿针对本机的显示路径，不会更改显示器颜色配置。若实际光标偏浅，可逐步提高补偿值；若偏深，则降低。不同电脑可能需要不同数值。部分特殊压缩格式的导入素材只支持补偿值 1.00，界面会说明。

## 本地数据

数据保存在用户的 `文档\CursorSkinManager`，包括导入素材、补偿缓存、大小/颜色偏好和恢复记录。首次启动不会读取或迁移其他指针工具的素材库。

Windows 已应用的指针会引用这个数据目录，使用期间请保留。分享工具时只分享 EXE 或干净的构建包，**不要附带个人数据目录**。

## 从源码构建

在 Windows PowerShell 或 PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

输出位于 `dist/`。构建脚本使用系统的 .NET Framework C# 编译器；应用图标由仓库内的几何绘图代码生成，没有下载素材，也没有嵌入指针资源。

可在已登录的 Windows 桌面执行功能验证：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

验证使用运行时生成的简单几何 CUR / ANI，不依赖第三方素材；测试过程中会临时应用测试光标，并在结束后恢复完整的原始指针设置。报告与临时素材位于 `artifacts/`，不会进入仓库。CI 仅执行构建和发布资源检查，避免在非交互式会话中更改指针。
